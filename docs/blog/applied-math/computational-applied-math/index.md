# 计算与应用数学 { #index }

这份笔记由几部分组成。第一部分是基本知识：常微分方程的基本理论、Green 函数与精确解法，以及差分方程。第二部分是局部分析：在常点、正则奇点与非正则奇点附近求线性微分方程的级数解与渐近行为，并讨论渐近级数的性质。之后是凸优化和 PDE 数值解（椭圆方程的有限差分方法）。
