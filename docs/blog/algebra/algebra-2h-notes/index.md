# 代数2-H笔记 { #index }

这份笔记分为两部分。前六章是域论与 Galois 理论：从域扩张、尺规作图与分裂域出发，经过可分扩张与正规扩张建立 Galois 对应，再讨论有限域、分圆域、Kummer 理论与方程的根式可解性。后四章是交换代数：环与模、局部化与整相关性、链条件与准素分解，最后到 Dedekind 整环与完备化。

定理与命题的证明放在折叠框中，点击即可展开；交换图由原 LaTeX 源码渲染为图片。
