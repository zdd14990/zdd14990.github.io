# 表示论 { #index }

这份笔记从结合代数的表示出发，先建立半单表示、密度定理与 Wedderburn 定理等一般结论，再系统讨论有限群的表示：Maschke 定理、特征标的正交关系、诱导表示与 Frobenius 互反律。之后转向具体的群——对称群 $S_n$ 与有限域上的 $\mathrm{GL}_2$、$\mathrm{SL}_2$——并介绍箭图表示与 Gabriel 定理，最后用 Okounkov–Vershik 的方法重新构造 $S_n$ 的表示。

证明放在折叠框中，点击即可展开；交换图与箭图由原 LaTeX 源码渲染为图片。
