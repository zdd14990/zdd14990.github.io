# 神话学引论随笔 { #top }

这学期选了一门神话学，课件来自梁君健老师。随笔最初把前五讲写在一篇里，后来越写越长，现在改成一讲一篇，这一页做目录和总结。各篇按课件顺序整理要点，中间夹着我自己的想法，并补了一些查到的资料和图片，引文和图片来源列在各篇文末。

这几讲有一个共同的意思：**神话从来不只是书里的故事**。它刻在砖石上，在庙会上唱出来，在庙里烧成纸钱，被史家删改、被小说重写，也由研究它的学者一遍遍重新写过。

## 小结 { #summary }

回头看，每一讲各有一个关键词：

- 第一讲是**形态**：神话存在于文献、口头、仪式和实物之间，并且不断在它们之间转写。西王母从甲骨上的「西母」一路走到天池景区导游口中。
- 第二讲是**作者**：神话学家也是神话的书写者。闻一多在民族危亡之际用伏羲和龙讲出了一个同源共祖的中国，这本身就是一次现代的「神话制作」。
- 第三讲是**结构**：神、鬼、祖先映照着官员、陌生人、亲属。民间宗教用帝国的语言组织社会，也在模仿中保留了偏离帝国的可能。
- 第四讲是**实践**：在白云山，神话被「做」出来。道士的醮仪和信众的迎会共用一座山、一张日程表，一个签筒为四个省区预测收成。
- 第五讲是**书写**：田野材料从来不是中性的，记录要一丝不苟，写作要把人写成「圆形」，也要把自己写进去。
- 第六讲是**层累**：李冰变成二郎神，纣王多出炮烙之刑，亚瑟从抵抗者变成征服者的祖先。顾颉刚说，他关心的不是古史的真相，而是它的变化。
- 第七讲是**语言**：动词需要施动者，于是风有了飞廉；一个动词就能让人记住不存在的碎玻璃。「风吹」和「空气流动」是两种语言，神话长在前一种里。
- 第八讲是**图像**：城门总画成正面，祖宗像上没有阴影，长城在舆图上越画越粗。程式不是对真实的背离，而是让真实可以被看见的形式。

把这些关键词连起来，我对「神话」的理解有了变化。它不是一个等待被考证真伪的「原始故事」，而是**一种社会用来讲述自身、安排秩序的方式**。蒋观云说的「植字」，闻一多说的「活动动机之口供」，王斯福说的「隐喻」，兰色姆说的「人为的形式」，顾颉刚说的「层累」，列维-斯特劳斯说的「元语言」，说的大概都是这件事。而研究神话的人，也在用民族志给它添上新的一层。
