# 第九章：弱拓扑、凸集分离与自反空间 { #chapter-09 }

## 1. 当测试函数不再稠密 { #section-1 }

第二章中，稠密测试函数上的有界数据唯一决定泛函。若测试空间 $M\subset X$ 不稠密，泛函在其闭包上仍唯一，但在整个 $X$ 上可能有不同扩张。

给定 $x_j\in X$ 和数 $c_j$，寻找 $f\in X^*$ 使 $f(x_j)=c_j$。必要条件是对所有有限系数族，

$$
\left|\sum_ja_jc_j\right|\le C\left\|\sum_ja_jx_j\right\|.
$$

它已经保证数据在 $M=\operatorname{span}\{x_j\}$ 上定义一个有界泛函。剩下的问题是怎样将它扩张，且不增加范数。这就是 Hahn–Banach 的具体动机。

## 2. Hahn–Banach：一个方向一个方向地扩张 { #section-2 }

!!! theorem "Hahn–Banach 定理"

    赋范空间 $X$ 的任意线性子空间 $M$ 上的有界线性泛函 $f$，都可扩张为 $F\in X^*$，且 $\|F\|=\|f\|$。$M$ 不要求闭，$X$ 不要求完备。

??? proof "实数情形：一维扩张与极大扩张"

    更一般地，设实次线性函数 $p$ 满足正齐次性和次可加性，且 $f(m)\le p(m)$。取 $z\notin M$，令扩张在 $z$ 的值为 $c$。

    保持支配关系恰要求

    $$
    \sup_{m\in M}[f(m)-p(m-z)]
    \le c\le
    \inf_{n\in M}[p(n+z)-f(n)].
    $$

    左端不超过右端，因为

    $$
    f(m)+f(n)=f(m+n)\le p(m+n)
    \le p(m-z)+p(n+z).
    $$

    故可以选 $c$，将 $f$ 扩张到 $M+\mathbb Rz$。按扩张包含关系排序，链的并仍是符合条件的泛函；Zorn 引理给出极大扩张。一维步骤说明极大定义域必是整个 $X$。

    取 $p(x)=\|f\|\|x\|$，同时对 $x,-x$ 使用支配关系，得到 $|F(x)|\le\|f\|\|x\|$，限制回 $M$ 给出范数等式。

??? proof "复数情形"

    先把 $\operatorname{Re}f$ 作为实线性泛函扩张为 $g$，再定义 $F(x)=g(x)-ig(ix)$。可检查 $F(ix)=iF(x)$，且 $F$ 在 $M$ 上等于 $f$。

    对 $F(x)\ne0$，选 $|\alpha|=1$ 使 $\alpha F(x)$ 为非负实数，则

    $$
    |F(x)|=g(\alpha x)\le\|g\|\|x\|.
    $$

    因此复扩张也不增加范数。单独扩张实部和虚部再随意拼接，未必保持所需范数。

若 $X$ 可分，可取可数个稠密方向，逐次作一维扩张，再连续延伸到闭包；不必使用一般形式的极大家族。可分性使一般的极大扩张构造转化为可数方向上的逐步扩张。

!!! theorem "泛函足以测量范数与距离"

    对每个 $x\in X$，

    $$
    \|x\|=\sup_{\|f\|\le1}|f(x)|.
    $$

    对闭线性子空间 $M$，

    $$
    \operatorname{dist}(x,M)
    =\sup\{|f(x)|:\|f\|\le1,\ f|_M=0\}.
    $$

??? proof "证明"

    上界由泛函估计直接得到。范数下界：在 $\mathbb Fx$ 上令 $f(\alpha x)=\alpha\|x\|$，再等范数扩张。

    距离公式的下界：令 $d=\operatorname{dist}(x,M)>0$，在 $M+\mathbb Fx$ 上定义 $f(m+\alpha x)=\alpha d$。因为 $\|m+\alpha x\|\ge|\alpha|d$，它的范数至多为 $1$，扩张后在 $x$ 上取值 $d$。$d=0$ 时两边都为零。

于是 $X^*$ 分离点，弱拓扑是 Hausdorff；这不是对偶定义本身就自动保证的结论。

## 3. 为什么凸性会给出分离泛函 { #section-3 }

### 3.1 有限维的最近点 { #section-3-1 }

在欧氏空间中，若闭凸集 $C$ 不含 $x_0$，选离 $x_0$ 最近的点 $y$。沿 $y+t(c-y)$ 变分距离，得到

$$
\langle x_0-y,c-y\rangle\le0,\qquad c\in C.
$$

因此向量 $x_0-y$ 定义一个把 $C$ 与 $x_0$ 严格分开的超平面。无限维一般范数下最近点未必存在，但可用 Minkowski 泛函保留同样的分离结构。

### 3.2 开凸集的规范函数 { #section-3-2 }

对含 $0$ 的开凸集 $U$，定义

$$
p_U(x)=\inf\{t>0:x\in tU\}.
$$

它有限、次线性，且 $U=\{p_U<1\}$。若 $B(0,r)\subset U$，则 $p_U(x)\le\|x\|/r$，保证由它支配的线性泛函连续。

!!! theorem "点与闭凸集的严格分离"

    若非空闭凸集 $C\subset X$ 不含 $x_0$，则存在 $f\in X^*$ 与实数 $a<b$，使

    $$
    \operatorname{Re}f(c)\le a<b\le\operatorname{Re}f(x_0)
    \quad\forall c\in C.
    $$

??? proof "证明"

    先在实空间证明。选 $0<r<\operatorname{dist}(x_0,C)$，令开凸集 $U=C+B(0,r)$。取 $c_0\in C$，平移得 $V=U-c_0$，它含 $0$，而 $z=x_0-c_0\notin V$，所以 $p_V(z)\ge1$。

    在 $\mathbb Rz$ 上定义 $g(tz)=t$，它被 $p_V$ 支配；对负 $t$，左端非正而规范函数非负。用次线性版 Hahn–Banach 扩张。于是 $g(z)=1$、$g(v)<1$ 对 $v\in V$ 成立。

    对 $c\in C$，$c-c_0+B(0,r)\subset V$，所以 $g(c-c_0)\le1-r\|g\|$。$g(z)=1$ 给出正间隙 $r\|g\|$，完成严格分离。复空间先按实空间处理，再用上一节的复化公式，将实分离泛函写成复泛函的实部。

## 4. 弱拓扑为什么适合凸问题 { #section-4 }

!!! definition "弱拓扑"

    $\sigma(X,X^*)$ 是使全部 $f\in X^*$ 连续的最弱拓扑。$x_\alpha\rightharpoonup x$ 指 $f(x_\alpha)\to f(x)$ 对每个 $f$ 成立。

    若空间本身是一个对偶 $Y^*$，它的弱-\* 拓扑 $\sigma(Y^*,Y)$ 只测试来自 $Y$ 的泛函；弱拓扑 $\sigma(Y^*,Y^{**})$ 测试更多对象。二者不能只按名称互换。

!!! theorem "凸集的弱闭包等于范数闭包"

    对凸集 $C$，$\overline C^{\,w}=\overline C^{\,\|\cdot\|}$。

??? proof "证明"

    范数拓扑更强，因此范数闭包包含于弱闭包。反过来，若 $x$ 不在范数闭包中，严格分离给出 $f$，使 $\operatorname{Re}f(x)$ 与 $C$ 上的值之间有正间隙。由 $f$ 定义的弱邻域便避开 $C$，所以 $x$ 也不在弱闭包中。

非凸集不能这样断言。例如无限维 Hilbert 空间的单位球面范数闭，却以正交单位向量列弱逼近 $0$。

!!! theorem "Mazur 引理"

    若 $x_n\rightharpoonup x$，则可以从每个尾部 $\{x_n,x_{n+1},\ldots\}$ 取有限凸组合 $y_n$，使 $\|y_n-x\|\to0$。

??? proof "证明"

    $x$ 属于每个尾部的弱闭包，因而属于其凸包的弱闭包；凸性将它变为范数闭包。选择误差小于 $1/n$ 的有限凸组合即可。

Hilbert 空间还有更具体的 Banach–Saks 结论：弱收敛列有子列，其算术平均强收敛。对弱零列递归取子列，使后取向量与已有向量的内积小于 $2^{-j}$；平均范数平方由对角项 $O(1/k)$ 和交叉项 $O(1/k^2)$ 控制，故趋于零。一般 Mazur 组合的权重则未必相等。

### 4.1 用泛函判断稠密性 { #section-4-1 }

对子空间 $M$，令 $M^\perp=\{f\in X^*:f|_M=0\}$，这里是对偶湮灭子，不是 Hilbert 内积正交补。Hahn–Banach 距离公式给出

$$
\overline M=\{x:f(x)=0\ \forall f\in M^\perp\}.
$$

因此证明测试函数稠密，可以转化为证明“与全部测试函数配对为零的泛函只能为零”。第七章 Fourier 唯一性正是这种思路。

## 5. 有限逼近、双对偶与自反性 { #section-5 }

### 5.1 自然嵌入 { #section-5-1 }

定义 $J:X\to X^{**}$，$Jx(f)=f(x)$。上一节范数公式说明 $J$ 是线性等距嵌入。

对 $T:X\to Y$，定义转置 $T':Y^*\to X^*$，$T'f=f\circ T$。有 $\|T'\|=\|T\|$、$T''J_X=J_YT$。它与 Hilbert 伴随通过 Riesz 表示联系，但两者作用的空间不同，不能只因都常写星号就认为相同。

### 5.2 Goldstine 定理与有限测试 { #section-5-2 }

!!! theorem "Goldstine 定理"

    $J(B_X)$ 在 $B_{X^{**}}$ 中弱-\* 稠密。也就是说，每个范数至多为 $1$ 的 $F\in X^{**}$，对有限个 $f_j\in X^*$ 的取值，都能由某个 $\|x\|\le1$ 任意逼近。

??? proof "证明：有限维凸集分离"

    令 $\Phi(x)=(f_1(x),\ldots,f_m(x))$。若 $(F(f_1),\ldots,F(f_m))$ 不在 $\Phi(B_X)$ 的闭包中，有限维分离给出复系数 $a_j$，使

    $$
    \operatorname{Re}F\left(\sum_ja_jf_j\right)
    >\sup_{\|x\|\le1}\operatorname{Re}\sum_ja_jf_j(x)
    =\left\|\sum_ja_jf_j\right\|.
    $$

    但 $\|F\|\le1$ 排除了这个严格不等式。故有限测试均可逼近；按有限测试集增大和误差缩小排序，便得到弱-\* 逼近网。

有限逼近的做法是：先解决有限个矩约束，再利用统一范数界取得极限。但极限可能只属于双对偶，未必仍在原空间。

!!! example "有限问题都有解，无限问题却离开原空间"

    在 $c_0$ 中要求全部坐标为 $1$。前 $N$ 个约束有解 $(1,\ldots,1,0,\ldots)$，范数始终为 $1$，但没有 $c_0$ 元素满足全部约束。它们在 $c_0^{**}=\ell^\infty$ 的弱-\* 极限是全为 $1$ 的数列。

### 5.3 自反性与弱紧性 { #section-5-3 }

!!! definition "自反空间"

    若自然嵌入 $J:X\to X^{**}$ 满射，称 $X$ 自反。要求的是这个具体嵌入满射，而不仅是与双对偶存在某个抽象同构。

!!! theorem "自反性的紧性刻画"

    Banach 空间 $X$ 自反，当且仅当闭单位球弱紧。

??? proof "证明"

    自反时，$J$ 将 $X$ 的弱拓扑对应到 $X^{**}$ 的弱-\* 拓扑，闭单位球对应整个双对偶闭单位球。Banach–Alaoglu 给出紧性。

    反过来，若 $B_X$ 弱紧，$J(B_X)$ 弱-\* 紧，因弱-\* 拓扑 Hausdorff，它闭。Goldstine 又说它在 $B_{X^{**}}$ 中稠密，故两者相等。缩放便得 $J$ 满射。

Hilbert 空间自反；在 $\sigma$-有限测度下，$1<p<\infty$ 的 $L^p$ 由两次对偶表示得到自反，$\ell^p$ 同理。自反空间的闭子空间自反，因为其单位球是原弱紧球中的弱闭子集。

当 $X$ 自反时，**在 $X^*$ 上**，弱拓扑 $\sigma(X^*,X^{**})$ 与弱-\* 拓扑 $\sigma(X^*,X)$ 相同。讨论任何弱-\* 拓扑时仍须说明前对偶。

!!! example "变分法的直接方法"

    在自反空间上，若非空约束集 $C$ 凸且范数闭，能量 $J$ 弱下半连续且强制，即 $\|u\|\to\infty$ 时 $J(u)\to\infty$，则存在最小值。

    取最小化序列，强制性保证有界；弱紧性给出收敛子网，凸闭集弱闭保证极限可行，弱下半连续保证能量不增加。若 $J$ 严格凸，极小点唯一。

## 6. 非自反空间的例子 { #section-6 }

### 6.1 $c_0$ 与 $\ell^1$ { #section-6-1 }

$c_0^*=\ell^1$、$c_0^{**}=\ell^\infty$。自然嵌入只得到趋于零的数列，所以 $c_0$ 不自反。

在收敛数列空间 $c\subset\ell^\infty$ 上，极限泛函 $L(x)=\lim x_n$ 的范数为 $1$。Hahn–Banach 将它扩张到整个 $\ell^\infty$。它杀掉每个 $e_n$，却在常数 $1$ 上取值 $1$，因此不可能由任何 $\ell^1$ 数列的坐标配对表示。这给出 $\ell^1{}^{**}$ 中不来自 $\ell^1$ 的元素，所以 $\ell^1$ 不自反。

$\ell^\infty$ 也不自反，因为它包含闭的非自反子空间 $c_0$。在 $L^1(0,1)$ 上，集中列 $n\mathbf1_{(0,1/n)}$ 没有弱收敛子网：任何可能极限都由远离零点的示性函数测试迫为零，但常数 $1$ 的测试值始终为 $1$。所以其单位球不弱紧。

### 6.2 $C[0,1]$ { #section-6-2 }

在一列互不相交、向 $0$ 聚集的小区间上取高度为 $1$ 的连续帐篷函数 $\phi_n$。映射

$$
(a_n)\in c_0\longmapsto\sum_na_n\phi_n
$$

等距嵌入 $C[0,1]$：支撑不交给出一致范数等式，$a_n\to0$ 保证在聚点连续。像闭，因此 $C[0,1]$ 含闭非自反子空间，也不自反。

## 7. 一个真正不唯一的正矩问题 { #section-7 }

令 $Y$ 为标准正态变量，$X=e^Y$，其 lognormal 测度在 $x>0$ 的密度为

$$
w(x)=\frac1{x\sqrt{2\pi}}e^{-(\log x)^2/2}.
$$

对 $|\varepsilon|\le1$，令 $w_\varepsilon(x)=[1+\varepsilon\sin(2\pi\log x)]w(x)$，仍是非负密度。

!!! theorem "不同测度具有全部相同的矩"

    对全部非负整数 $n$，$\int_0^\infty x^nw_\varepsilon(x)\,\mathrm dx=e^{n^2/2}$，与 $\varepsilon$ 无关。

??? proof "证明"

    代换 $y=\log x$，新增部分的积分为

    $$
    \operatorname{Im}\mathbb E[e^{(n+2\pi i)Y}]
    =e^{(n^2-4\pi^2)/2}\sin(2\pi n)=0.
    $$

    $n=0$ 也表明总质量不变。不同参数的密度并非几乎处处相同，所以确实是不同测度。它们所有矩都有限，却无法由这些矩区分。

此例说明无界区间上多项式的测试能力可能不足，第四章的正性主要保证存在，而不自动保证唯一。矩空间上的对称乘法算子与不同自伴扩张也提供了理解不唯一性的另一条路线。

## 8. 泛函扩张、商空间与有限维分离 { #section-8 }

约定 $V,W$ 为实或复赋范空间。复空间中的凸性和分离使用其底层实向量空间及泛函的实部；伴随仍留给 Hilbert 空间，连续对偶之间的映射记为转置。

### 把部分测试值延拓出去 { #topic-9-1-1 }

一个有界泛函只知道子空间上的数据，Hahn–Banach 保证扩到全空间时不增大范数。一维允许区间负责局部可行性，极大扩张负责穷尽全部方向。

!!! theorem "定理 9.1.1：Hahn–Banach 定理"

    任意线性子空间 $U\subset V$ 上的有界线性泛函 $\phi$ 都可延拓为 $\Phi\in V^*$，且 $\|\Phi\|=\|\phi\|$。子空间不必闭，原空间不必完备。

??? proof "证明 9.1.1"

    实情形先用 9.1.2 每次扩张一个方向。把所有保持范数界的扩张按定义域包含排序，链的并仍为良定义的同界泛函；Zorn 引理给极大扩张。如果定义域尚未穷尽空间，一维扩张会违反极大性，故得到全空间延拓。限制使延拓范数不小于原范数，与保界合起来等号成立。

    复情形将实部作为实泛函等范数延拓，再用 9.1.5 的逆式复线性化。它在原复子空间上还原原泛函，且保持范数。

!!! theorem "引理 9.1.2：Helly 的一维扩张"

    实赋范空间中，$\|\phi\|\leq1$、$e\notin U$ 时，可将 $\phi$ 延拓到 $U+\mathbb Re$ 并保持范数至多一。允许的 $\Phi(e)$ 构成非空闭区间。

??? proof "证明 9.1.2"

    令 $\Phi(u+te)=\phi(u)+tc$。正负 $t$ 的范数限制经缩放等价于对全部 $u\in U$，

    $$
    \phi(u)-\|u-e\|\leq c\leq\|u+e\|-\phi(u).
    $$

    任意左端与任意右端的比较由 $\phi(u)+\phi(v)\leq\|u+v\|\leq\|u-e\|+\|v+e\|$ 得到。因此左端上确界不超过右端下确界；两端用 $u=0$ 夹在有限范围内，构成非空闭区间。在其中选 $c$，全部范数限制成立。

!!! theorem "命题 9.1.5：复泛函与实部"

    复线性泛函到实线性泛函的 $\phi\mapsto\operatorname{Re}\phi$ 为实线性双射，逆式为 $\phi(v)=f(v)-if(iv)$；有界时 $\|\phi\|=\|f\|$。

??? proof "证明 9.1.5"

    给实线性 $f$，令 $\phi(v)=f(v)-if(iv)$，则 $\phi(iv)=i\phi(v)$，配合实线性给复线性，且实部正是 $f$。逆式唯一。显然 $\|f\|\leq\|\phi\|$；对任意 $v$，选模为一的 $a$ 使 $a\phi(v)=|\phi(v)|$，则 $|\phi(v)|=f(av)\leq\|f\|\|v\|$，给出反向范数界。

### 用对偶看商空间 { #topic-9-2-1 }

商范数测量离子空间的距离，湮灭子记录所有忽略该子空间的测试。有限维测试的值域与范数公式将这两种描述精确对应起来。

!!! definition "定义 9.2.1：典范双对偶映射"

    定义 $J_V(v)(\phi)=\phi(v)$，它线性且 $\|J_V\|\leq1$。Hahn–Banach 将该估计加强为等距性。

??? proof "证明 9.2.1"

    上界由 $|\phi(v)|\leq\|\phi\|\|v\|$ 得到。若 $v\ne0$，在一维张成上定义 $\phi(av)=a\|v\|$，它范数为一；Hahn–Banach 延拓后仍范数为一且取值 $\|v\|$，所以 $\|J_Vv\|\geq\|v\|$，得到等距。

!!! theorem "命题 9.2.3：商范数"

    闭子空间 $U$ 的商空间取 $\|v+U\|=\operatorname{dist}(v,U)=\inf_{u\in U}\|v+u\|$。闭性保证零范数仅对应零陪集。

??? proof "证明 9.2.3"

    变换代表元不改变到 $U$ 的距离。分别取近乎达到下确界的 $u,w\in U$，三角不等式给商范数的三角不等式；非零标量通过 $U$ 的缩放不变性给齐次性。零范数意味着 $v$ 位于 $U$ 的闭包，闭性使 $v\in U$，故确为范数。

!!! theorem "定理 9.2.4：通过商空间因子化"

    商映射 $\pi_U$ 诱导线性等距嵌入 $\mathcal L(V/U,W)\to\mathcal L(V,W)$，$T\mapsto T\pi_U$，像恰为在 $U$ 上为零的算子。

??? proof "证明 9.2.4"

    商映射范数至多一，所以 $\|T\pi_U\|\leq\|T\|$。反向任意陪集 $q$ 可取代表 $v$ 使 $\|v\|<\|q\|+\varepsilon$，于是 $\|Tq\|\leq\|T\pi_U\|(\|q\|+\varepsilon)$；令误差趋零得等范数。若算子在 $U$ 上为零，其值不依赖代表元，恰可因子化，并由相同估计保证因子有界。

!!! definition "定义 9.2.5：湮灭子与预湮灭子"

    对 $E\subset V^*$、$F\subset V$，定义 ${}^\perp E=\{v:\phi(v)=0\ \forall\phi\in E\}$、$F^\perp=\{\phi:\phi(v)=0\ \forall v\in F\}$。二者均为闭线性子空间，后者还弱-\* 闭。

!!! theorem "推论 9.2.6：商空间的对偶"

    $(V/U)^*$ 等距同构于 $U^\perp$，同构为 $\psi\mapsto\psi\pi_U$。

??? proof "证明 9.2.6"

    将 9.2.4 取 $W=\mathbb F$，像条件正是泛函消去 $U$，即属于 $U^\perp$。等距及满射到该像直接给出对偶同构。

!!! theorem "推论 9.2.7：预湮灭子的商"

    对线性 $X\subset V^*$，$(V/{}^\perp X)^*\cong({}^\perp X)^\perp$。若 $X$ 有限维，右侧等于 $X$；一般应取 $X$ 的弱-\* 闭包。

??? proof "证明 9.2.7"

    前一同构由 9.2.6。若某个泛函不在 $X$ 的弱-\* 闭包，弱-\* 分离只需有限个原空间求值坐标：在有限维坐标像中分离，得到某个 $v$ 消去 $X$ 却不消去该泛函。因此 $({}^\perp X)^\perp$ 恰是弱-\* 闭包。有限维子空间在此 Hausdorff 拓扑中闭，可直接由有限个独立测试坐标验证，故有限维时就是 $X$。

!!! theorem "定理 9.2.9：有限维测试的值域"

    若 $X\subset V^*$ 有限维，则 $v+{}^\perp X\mapsto J_V(v)|_X$ 为 $V/{}^\perp X$ 到 $X^*$ 的线性双射。

??? proof "证明 9.2.9"

    核正是 $ {}^\perp X$，所以诱导映射单射。若其有限维值域是 $X^*$ 的真子空间，有限维代数对偶中存在非零 $\phi\in X$ 消去全部求值，即 $\phi(v)=0$ 对全部 $v$ 成立，矛盾。故满射。

!!! theorem "引理 9.2.10：有限维测试的范数"

    上述双射为等距同构，即 $\operatorname{dist}(v,{}^\perp X)=\sup_{\phi\in X,\,\|\phi\|\leq1}|\phi(v)|$。商范数的下确界不必由某个代表元达到。

??? proof "证明 9.2.10"

    商空间 $Q=V/{}^\perp X$ 的对偶由 9.2.7 等距识别为 $X$。Hahn–Banach 的等距求值性质给 $\|q\|=\sup_{\|\phi\|_X\leq1}|\phi(q)|$。代入 $q=v+{}^\perp X$ 即得公式；它只确定下确界，没有宣称存在最小范数代表。

!!! theorem "定理 9.2.11：有限维自反性"

    有限维赋范空间的典范映射 $J_V:V\to V^{**}$ 为线性等距同构。

??? proof "证明 9.2.11"

    对单位向量用 9.3.5 分离开单位球与该点，9.3.1 给分离泛函范数至多一且该点求值为一；复情形用 9.1.5 恢复复泛函。于是典范映射等距、单射。有限维下 $\dim V=\dim V^{**}$，所以也满射。这给出了通过有限维凸分离得到自反性的证明。

### 先在有限维理解分离 { #topic-9-3-1 }

范数球的包含关系可以用一个半空间的不等式检测。有限维中，最近点和射线退出点给出分离超平面的几何构造；边界情形还需取极限。

!!! theorem "引理 9.3.1：范数与半空间"

    对实线性 $\phi$ 和 $a,b>0$，$\|\phi\|\leq b/a$ 当且仅当半径 $a$ 的球包含于 $\{v:\phi(v)\leq b\}$。开球或闭球给出相同判据。

??? proof "证明 9.3.1"

    范数上界立即使半径 $a$ 的球落在半空间。反向对单位 $v$ 及 $a'<a$，有 $\phi(a'v)\leq b$，对 $-v$ 也成立，故 $|\phi(v)|\leq b/a'$。令 $a'\uparrow a$ 得范数界，因而开球和闭球版本一致。

!!! definition "定义 9.3.2：线段与凸集"

    $[p,q]$、$(p,q)$ 等为仿射映射 $t\mapsto(1-t)p+tq$ 对相应实区间的像；射线 $[p,\infty q)$ 使用 $t\geq0$。集合凸指包含任意两点间的闭线段。

!!! theorem "引理 9.3.3：射线的退出点"

    若开凸集 $\Omega$ 包含 $p$，而从 $p$ 指向 $v$ 的射线与 $\Omega$ 的交在 $p+r(v-p)$ 之前结束，其中 $0<r<1$，则 $v\notin\Omega$。凸性保证射线上位于集合内的参数形成区间。

??? proof "证明 9.3.3"

    射线与凸集的交在参数上为凸子集，开性使它为含零的相对开区间。若退出参数为 $r<1$，参数 $1$ 不在该区间，所以 $v\notin\Omega$。特别当退出点是边界点时，更远的射线点也在闭包外：否则用含零的小球与该闭包点作凸组合，会把退出点推进到内部。

!!! theorem "引理 9.3.4：非零实泛函是开映射"

    非零有界实线性泛函 $\phi:W\to\mathbb R$ 将开集映为开集；在一个 $\phi(e)\ne0$ 的方向上移动即可在像中得到开区间。

??? proof "证明 9.3.4"

    取 $\phi(e)\ne0$。若 $B(w,\delta)$ 包含于给定开集，那么 $w+te$ 在 $|t|<\delta/\|e\|$ 时仍在其中，其像覆盖以 $\phi(w)$ 为中心的开区间。每个像点都有这种邻域，所以像开。

!!! theorem "定理 9.3.5：有限维开凸集分离"

    有限维实空间中，若开凸 $\Omega$ 包含零，$v\notin\Omega$，则有 $\phi\in V^*$ 满足 $\phi(v)=1$ 且 $\phi(x)<1$ 对所有 $x\in\Omega$ 成立。

??? proof "证明 9.3.5"

    换成等价欧氏范数。先假设 $v$ 在 $\overline\Omega$ 外，闭凸集的距离由有界最小化序列取得于 $p\in\overline\Omega$。沿 $p$ 指向任意 $x\in\overline\Omega$ 的线段求距离平方的右导数，得 $\langle v-p,x-p\rangle\leq0$。因零在内部，$\langle v-p,v\rangle>0$，故用该分母归一化的泛函满足 $\phi(v)=1$、$\phi(\Omega)\leq1$。

    若 $v$ 在边界，沿从零出发的射线取外点 $v_k=(1+1/k)v$；凸性与零的内部性保证这些点在闭包外。各分离泛函因 $\Omega$ 包含固定小球而具有统一范数界，有限维紧性给收敛子列，极限满足弱分离和 $\phi(v)=1$。最后非零泛函是开映射，若内部点取值为一，附近必有取值大于一的点，矛盾；故不等式严格。

??? proof "一维扩张的取值区间"

    令 $\Phi(u+te)=\phi(u)+tc$。保持范数至多一等价于对全部 $u\in U$，$\phi(u)-\|u-e\|\leq c\leq\|u+e\|-\phi(u)$。任一左端不大于任一右端，因为 $\phi(u+w)\leq\|u+w\|\leq\|u-e\|+\|w+e\|$。因此取左端上确界与右端下确界之间的 $c$ 即可。反复扩张配合 Zorn 得到全空间的扩张；复情形先扩张实部再由逆式恢复。

    有限维商空间与 $X^*$ 的配对非退化：若 $X$ 中某个泛函在全部 $V$ 上为零，它自身为零，故测试映射满射。商范数等式来自商对偶的单位球范数公式以及 $({}^\perp X)^\perp=X$。

## 9. 一般凸集分离与弱闭包 { #section-9 }

### 从局部分离到全空间 { #topic-9-4-1 }

有限维分离加弱-\* 紧性是一条路线，Minkowski 泛函加受支配延拓是另一条路线。严格分离还需要正的间隙，闭集与紧集条件正好保证这个间隙。

!!! theorem "定理 9.4.1：开凸集分离"

    任意赋范空间中，开凸集 $\Omega$ 包含零且 $v\notin\Omega$ 时，有 $\phi\in V^*$，使 $\operatorname{Re}\phi(v)=1$、$\operatorname{Re}\phi(x)<1$ 对全部 $x\in\Omega$ 成立。

??? proof "证明 9.4.1"

    第一种证明用有限逼近。对包含 $v$ 的每个有限维子空间 $U$，9.3.5 给分离泛函；$\Omega$ 包含半径 $a$ 的球，使其范数至多 $1/a$。Hahn–Banach 将其同界延拓到 $V$，Banach–Alaoglu 给弱-\* 收敛子网。任何固定点最终包含于这些测试空间，故极限满足 $\phi(v)=1$、$\phi(\Omega)\leq1$；开映射性质使后者严格。

    第二种证明定义 Minkowski 泛函 $p(x)=\inf\{r>0:x\in r\Omega\}$。球的包含给 $p(x)\leq\|x\|/a$，凸性给次可加性，正缩放给正齐次性。$p(v)\geq1$，而 $\Omega=\{p<1\}$。在 $\mathbb Rv$ 上定义 $f(tv)=t$，对 $t\geq0$ 有 $f\leq p$，对 $t<0$ 因 $p\geq0$ 也成立。使用次线性版本的一维扩张及 Zorn 引理延拓 $f\leq p$，便有 $f(v)=1$、$f(\Omega)<1$；同时 $|f(x)|\leq\|x\|/a$，故连续。复情形通过实部对应处理。

!!! theorem "定理 9.4.3：闭集与紧集的严格分离"

    非空不交凸集 $A,B$，其中一个闭、另一个紧，则存在 $\phi\in V^*$ 及实 $a<b$，使 $\operatorname{Re}\phi(A)\leq a<b\leq\operatorname{Re}\phi(B)$。

??? proof "证明 9.4.3"

    紧集与不交闭集的距离为正：在紧集上，到闭集的连续正距离取得正最小值。令 $C=A-B$，则零不在其闭包；取小球厚化 $C$ 得不含零的开凸集。对该集与零使用开凸分离，得到非零实泛函，厚化的小球使原两集间出现固定正间隙。调整符号后可取 $\sup\operatorname{Re}\phi(A)<\inf\operatorname{Re}\phi(B)$，在间隙中选 $a<b$ 即得结果。

!!! theorem "定理 9.4.5：闭凸集的最佳逼近"

    Hilbert 空间中，每个非空闭凸集 $A$ 和 $v\notin A$ 有唯一 $\xi\in A$ 满足 $\|v-\xi\|=\operatorname{dist}(v,A)$。它由 $\operatorname{Re}\langle v-\xi,y-\xi\rangle\leq0$（$y\in A$）刻画。

??? proof "证明 9.4.5"

    取距离最小化序列 $x_n\in A$。中点仍在 $A$，平行四边形恒等式给

    $$
    \|x_n-x_m\|^2
    \leq2\|v-x_n\|^2+2\|v-x_m\|^2-4d^2\to0.
    $$

    完备性及闭性给极限 $\xi\in A$，达到距离。沿 $\xi+t(y-\xi)$ 的距离平方右导数非负，得到刻画不等式。反向展开 $\|v-y\|^2$，该不等式使它至少为 $\|v-\xi\|^2+\|y-\xi\|^2$，因此既保证最小性也保证唯一。

### 凸性连接弱极限和范数极限 { #topic-9-5-1 }

弱拓扑只要求泛函测试连续，通常比范数拓扑粗。凸集可由连续泛函分离，因此两种闭包在凸集上相同，弱极限也能用有限凸组合恢复为范数极限。

!!! definition "定义 9.5.1：一般赋范空间的弱拓扑"

    $\sigma(V,V^*)$ 由全部连续线性泛函的数值坐标诱导，等价于经 $J_V$ 拉回 $V^{**}$ 的弱-\* 拓扑。网弱收敛当且仅当所有 $\phi(v_\alpha)$ 收敛。

!!! theorem "推论 9.5.3：凸集的两种闭包"

    凸集的范数闭包与弱闭包相同。因此范数闭凸集弱闭。

??? proof "证明 9.5.3"

    弱拓扑较粗，范数闭包包含于弱闭包。若点在范数闭凸包外，9.4.3 将该点与闭凸包严格分离；分离泛函弱连续，提供一个弱开邻域不碰凸包，所以该点也不在弱闭包。这给出反向包含。

!!! theorem "推论 9.5.5：凸组合恢复范数极限"

    定义 $\operatorname{conv}E$ 为有限非负系数、系数和为一的组合。若 $E$ 中有网弱趋于 $v$，则存在 $\operatorname{conv}E$ 中的序列范数趋于 $v$；对序列尾集分别应用得到 Mazur 型尾部凸组合。

??? proof "证明 9.5.5"

    弱极限 $v$ 属于 $E$ 的弱闭包，从而属于 $\operatorname{conv}E$ 的弱闭包。9.5.3 将其转成范数闭包，每个半径 $1/n$ 的球于是含一个有限凸组合，得到范数收敛序列。若原序列弱收敛，$v$ 属于每个尾集的弱闭包，对第 $n$ 个尾集选误差小于 $1/n$ 的凸组合，便得 Mazur 型尾部结论。

!!! theorem "推论 9.5.7：双湮灭子"

    任意线性子空间 $U$ 满足 $\overline U={}^\perp(U^\perp)$，所以 $U$ 稠密当且仅当 $U^\perp=\{0\}$。

??? proof "证明 9.5.7"

    闭包内的向量当然被 $U^\perp$ 消去。反向若 $v\notin\overline U$，闭子空间与点的严格分离给泛函；由于 $\overline U$ 是线性空间，分离泛函必须在其上为零，否则缩放会使值无界。该泛函却不消去 $v$，所以 $v\notin{}^\perp(U^\perp)$。

### 双对偶中的有限测试逼近 { #topic-9-6-1 }

典范映射保留范数，转置把算子作用拉回测试泛函。Goldstine 说明有限测试无法区分单位球与其双对偶单位球中的点；自反性则要求这些双对偶点确实来自原空间。

!!! theorem "命题 9.6.1：有界映射的弱连续性"

    任意有界线性 $T:V\to W$ 对两侧弱拓扑连续，因为每个 $\psi\in W^*$ 的复合 $\psi T$ 属于 $V^*$。

??? proof "证明 9.6.1"

    若 $v_\alpha\rightharpoonup v$，对每个 $\psi\in W^*$，有 $\psi(Tv_\alpha)=(\psi T)(v_\alpha)\to(\psi T)(v)$，因为 $\psi T\in V^*$。这正是 $Tv_\alpha\rightharpoonup Tv$ 的定义。

!!! definition "定义 9.6.2：转置"

    定义 $T':W^*\to V^*$，$T'\psi=\psi\circ T$；其有界且范数至多为 $\|T\|$。

!!! theorem "定理 9.6.3：双对偶与转置等距"

    $J_V$ 是线性等距嵌入；更一般地 $T\mapsto T'$ 为算子空间间的线性等距嵌入，$\|T'\|=\|T\|$。

??? proof "证明 9.6.3"

    $J_V$ 等距已由一维泛函延拓证明。对 $T$，有 $\|T'\|\leq\|T\|$；反向对每个单位 $v$，$W$ 的等距求值给 $\|Tv\|=\sup_{\|\psi\|\leq1}|\psi(Tv)|\leq\|T'\|$。再对 $v$ 取上确界得到等号。线性显然，等距也保证单射。

!!! theorem "推论 9.6.5：对偶分离点"

    $V^*$ 分离 $V$ 的点，故弱拓扑为 Hausdorff 拓扑。

??? proof "证明 9.6.5"

    对不同 $v,w$，等距 $J_V$ 使 $J_V(v-w)\ne0$，故存在 $\phi$ 取不同值。分离两个标量值的小开邻域拉回便给弱拓扑中的不交邻域，因此 Hausdorff。

!!! definition "定义 9.6.6：自反空间"

    $J_V$ 满射时称 $V$ 自反，即全部 $V^*$ 上的有界泛函都来自某个 $v$ 的求值。自反空间自动完备，因为双对偶完备。

!!! definition "定义 9.6.11：一般全连续映射"

    有界线性 $T:V\to W$ 全连续，指其闭单位球的限制由弱拓扑到值域范数拓扑连续。

!!! theorem "定理 9.6.13：自反定义域上的紧性"

    若 $V$ 自反，则以下等价：$T$ 紧；$T$ 全连续；双线性配对 $(\psi,v)\mapsto\psi(Tv)$ 在 $W^*$ 的弱-\* 单位球与 $V$ 的弱单位球的乘积上联合连续。

??? proof "证明 9.6.13"

    自反性使弱单位球经 $J_V$ 同构于双对偶的弱-\* 单位球，后者紧。故全连续推出紧。紧映射把弱收敛网的像任何范数聚点都识别为弱极限，反证子网论证便给全连续。

    若像强收敛，与可变弱-\* 单位球测试的配对误差由范数差和固定向量测试差控制，得到联合连续。反向用 9.6.14 将联合配对连续性恢复成像的范数收敛。三个条件遂等价。

!!! theorem "引理 9.6.14：联合对偶测试判定范数"

    单位球中 $\eta_\alpha\rightharpoonup\eta$，则 $\eta_\alpha$ 在范数下收敛到 $\eta$ 当且仅当对每个独立指标的弱-\* 收敛单位球网 $\psi_\nu\to\psi$，乘积网 $\psi_\nu(\eta_\alpha)\to\psi(\eta)$。

??? proof "证明 9.6.14"

    若范数收敛，配对误差至多为 $\|\eta_\alpha-\eta\|+|\psi_\nu(\eta)-\psi(\eta)|$，在乘积指标上趋零。反向若范数不收敛，取子网使距离至少为 $\varepsilon$，Hahn–Banach 选单位泛函 $\psi_\alpha$ 使 $|\psi_\alpha(\eta_\alpha-\eta)|\geq\varepsilon/2$。Banach–Alaoglu 再给弱-\* 收敛子网。对固定 $\eta$ 的测试已收敛，上述正下界遂使配对沿对角子网不能趋于要求值，与乘积网收敛矛盾。

!!! theorem "推论 9.6.15：自反空间中的紧转置"

    若 $V,W$ 自反，则 $T:V\to W$ 紧当且仅当 $T':W^*\to V^*$ 紧。更一般的 Banach 空间结论为 Schauder 定理。

??? proof "证明 9.6.15"

    自反时 $W^*$ 的弱拓扑等于由 $W$ 求值的弱-\* 拓扑。于是 $T$ 的联合连续配对 $(\psi,v)\mapsto\psi(Tv)$，交换两变量后就是 $T'$ 的相同判据，因为 $V^{**}=J_V(V)$。9.6.13 两次应用得到紧性等价。

!!! theorem "定理 9.6.16：Goldstine 定理"

    $J_V(B_V)$ 在 $V^{**}$ 闭单位球中弱-\* 稠密，故 $J_V(V)$ 在双对偶中弱-\* 稠密。这里不要求原空间完备。

??? proof "证明 9.6.16"

    固定有限个测试，其张成记为 $X\subset V^*$，并取 $F\in B_{V^{**}}$。限制 $F|_X$ 的范数至多一，9.2.9–9.2.10 给一个陪集代表，能以 $\|v\|\leq1+\delta$ 精确实现这些测试值。将 $v$ 除以 $1+\delta$ 使它落在单位球，有限个测试误差随 $\delta\downarrow0$ 消失。因此每个弱-\* 基本邻域均碰到 $J_V(B_V)$，证明稠密。

!!! theorem "推论 9.6.17：自反的弱紧判据"

    赋范空间自反当且仅当其闭单位球弱紧。

??? proof "证明 9.6.17"

    自反方向由 Banach–Alaoglu。反向弱紧单位球经 $J_V$ 映为弱-\* 紧集，在 Hausdorff 双对偶中闭；Goldstine 又使它在双对偶单位球稠密，故两球相同。缩放后 $J_V$ 满射，即自反。

### 检测自反性的失败 { #topic-9-7-1 }

点分离只要求测试族没有共同消去的非零向量，范数稠密则更强。非自反空间会出现分离点却不范数稠密的测试族，说明双对偶中仍有原空间外的信息。

!!! theorem "命题 9.7.1：离散 $C_0$ 的对偶"

    对任意离散集合 $X$，$C_0(X,\mathbb F)^*\cong\ell^1(X,\mathbb F)$ 等距，同构为 $f\mapsto[g\mapsto\sum_Xfg]$。

??? proof "证明 9.7.1"

    若 $a\in\ell^1(X)$，求和泛函范数至多 $\|a\|_1$；用有限集上的相位测试得到反向界。反过来对 $\Lambda\in C_0(X)^*$，令 $a_x=\Lambda(\mathbf1_{\{x\}})$。在任意有限集取相位，得 $\sum_{x\in F}|a_x|\leq\|\Lambda\|$，所以 $a\in\ell^1(X)$。有限支集函数在 $C_0$ 一致稠密，故 $\Lambda(g)=\sum a_xg(x)$，得到全部表示及等距性。

!!! theorem "定理 9.7.4：非自反的测试族判据"

    $V$ 非自反，当且仅当存在分离 $V$ 的点的 $X\subset V^*$，使 $\overline{\operatorname{span}X}$ 在 $V^*$ 中为真子空间。

??? proof "证明 9.7.4"

    若 $V$ 非自反，取 $F\in V^{**}\setminus J_V(V)$，令 $X=\ker F$。它是范数闭真子空间。若 $v$ 被 $X$ 全部消去，则 $J_Vv$ 与 $F$ 有相同核包含，代数线性关系使 $J_Vv=cF$；除 $v=0$ 外这会迫使 $F\in J_V(V)$，矛盾。因此 $X$ 分离点。

    反向若 $X$ 分离点而 $Y=\overline{\operatorname{span}X}$ 真，Hahn–Banach 在 $V^*$ 上给非零 $F$ 消去 $Y$。若 $V$ 自反，$F=J_Vv$，点分离使 $v=0$，与 $F\ne0$ 矛盾。

!!! theorem "推论 9.7.7：对偶的自反性"

    若 $V$ 是 Banach 空间，则 $V$ 自反当且仅当 $V^*$ 自反。

??? proof "证明 9.7.7"

    若 $V$ 自反，对任意 $F\in V^{***}$，定义 $\phi(v)=F(J_Vv)$。全部 $G\in V^{**}$ 都为 $J_Vv$，于是 $F(G)=\phi(v)=G(\phi)$，所以 $V^*$ 自反。反向若 $V^*$ 自反而 $J_V(V)$ 是真子空间，Banach 性使等距像闭；Hahn–Banach 给非零 $F\in V^{***}$ 消去此像。但 $F=J_{V^*}\phi$，消去条件就是 $\phi(v)=0$ 对全部 $v$，矛盾。所以 $J_V$ 满射。

### 核与余维由转置对应 { #topic-9-8-1 }

闭像的湮灭子就是转置的核。对紧算子的非零参数，核和像的稳定分解把这些空间缩到有限维，秩零度公式遂给四个维数的相等。

!!! definition "定义 9.8.1：指定测试族的弱拓扑"

    对 $X\subset V^*$，$\sigma(V,X)$ 由 $v\mapsto(\phi(v))_{\phi\in X}$ 的乘积拉回拓扑定义。$X=V^*$ 给通常弱拓扑；对偶空间上由原空间求值给弱-\* 拓扑。

!!! theorem "定理 9.8.6：Fredholm 的核与余维"

    Banach 空间上的紧 $T$ 和 $\lambda\ne0$ 满足 $\dim\ker(T-\lambda)=\dim V/\operatorname{ran}(T-\lambda)=\dim\ker(T'-\lambda)=\dim V^*/\operatorname{ran}(T'-\lambda)<\infty$。像闭，故商空间为赋范空间。

??? proof "证明 9.8.6"

    令 $A=T-\lambda$。先说明像闭：若没有 $\|Av\|\geq c\,\operatorname{dist}(v,\ker A)$，利用有限维核选距核归一化的有界代表，再用紧性和 $Av_n\to0$，会得到距核为一的向量却趋于核的矛盾。该下界及商空间完备性使像闭；$A^n$ 是非零标量加紧算子，同理其像闭。

    核链和像链由第八章的三角链判据最终稳定。取共同稳定次数 $n$，令 $N=\ker A^n$、$R=A^nV$。$N$ 有限维，且 $N\cap R=0$：若 $A^ny\in N$，稳定性使 $y\in N$。又 $A^nV=A^{2n}V$ 使每个 $v$ 可写成 $v=(v-A^ny)+A^ny$，前项在 $N$，所以 $V=N\oplus R$。$A$ 在 $R$ 上可逆，在 $N$ 上为有限维算子。有限维秩零度公式于是给 $\dim\ker A=\dim V/\operatorname{ran}A<\infty$。

    紧转置结论可直接证明：$K=\overline{T(B_V)}$ 紧，对偶单位球限制到 $K$ 是一致有界且等度连续的标量函数族，有限网论证使它在一致范数下全有界；而此范数差正是 $\|T'\psi-T'\chi\|$。$V^*$ 完备使 $T'$ 紧。因此上述核余维等式也用于 $A'=T'-\lambda$。最后 $\ker A'=(\operatorname{ran}A)^\perp\cong(V/\operatorname{ran}A)^*$，且像闭，故中间两个有限维数相等，四个量全部相同。

??? proof "严格分离、Goldstine 与自反性"

    开凸集的 Minkowski 泛函是次线性的，且由原点附近的小球控制；在 $\mathbb Rv$ 上规定值为一，再作受它支配的 Hahn–Banach 扩张，得到连续分离泛函。闭凸集与紧凸集不交时，两者之差闭且不含零，零附近有一个小球与它不交；加入更小球后仍不交，开凸集分离产生严格间隙。

    若点在凸集范数闭包外，严格分离给出一个弱邻域与凸集不交，因此也不在弱闭包内。Goldstine 的一个弱-\* 邻域只涉及有限个 $V^*$ 元素；在它们张成的有限维测试空间中，商范数的等距性允许用范数至多一的原空间向量任意逼近这些测试值。

    自反时，双对偶球的弱-\* 紧性就是原空间球的弱紧性。反向，弱紧的 $J_V(B_V)$ 在双对偶球中弱-\* 闭，而 Goldstine 又保证稠密，故等于整个球，$J_V$ 满射。紧算子的像有限逼近则与全连续性的联合测试相对应；Fredholm 的核余维等式可由有限维块分解或核像的湮灭关系得到。

## 10. 练习 { #section-10 }

!!! problem "练习 1：为什么凸性不可删除"

    在无限维 Hilbert 空间中，证明单位球面不是弱闭集；但闭单位球是弱闭集。

??? proof "解"

    正交单位列弱趋于 $0$，而 $0$ 不在球面。闭单位球可写成 $\bigcap_{\|y\|\le1}\{x:|\langle y,x\rangle|\le1\}$，是弱闭集；也可用凸集闭包定理。

!!! problem "练习 2：把弱零列变成强零组合"

    在 $\ell^2$ 中计算 $y_N=N^{-1}\sum_{n=1}^Ne_n$ 的范数。

??? proof "解"

    正交性给出 $\|y_N\|^2=N/N^2=1/N$。每个 $e_n$ 的范数都是 $1$，但平均强趋于零，直观展示 Mazur 与 Banach–Saks 的作用。

!!! problem "练习 3：矩数据只看到一部分方向"

    在 $\mathbb R^2$ 上给定 $f(1,0)=1$，使用 Euclidean 范数，描述全部线性扩张，并找范数最小的扩张。

??? proof "解"

    扩张为 $f_a(x,y)=x+ay$，范数为 $\sqrt{1+a^2}$。全部扩张不唯一，但保持原范数 $1$ 的扩张只能取 $a=0$。Hahn–Banach 保证等范数扩张存在，并不保证所有问题的等范数扩张唯一。
