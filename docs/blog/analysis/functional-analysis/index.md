# 泛函分析学习笔记 { #index }

把函数当作未知量时，有限维线性代数中的许多习惯需要重新检查：有界序列未必有范数收敛子列，稠密像未必是满射，微分表达式也不能单独确定一个算子。泛函分析用空间、拓扑、对偶和定义域，把这些问题放在能够进行估计和取极限的框架中。

这套笔记围绕变分问题、矩问题与积分方程展开。每章给出概念的动机、定义与结果的完整条件、典型计算及反例。带编号的定理、命题、引理和推论后紧接各自的证明框，展开后可以查看构造、估计和极限步骤；练习解答也放在折叠框中。

## 2. 理论之间的连接 { #section-2 }

对偶空间描述测试函数上的线性作用。测度表示把这种作用写成积分，Hilbert 空间的 Riesz 表示把它写成内积，谱定理进一步把算子写成乘法。它们共享的步骤是：先在较小的测试集合上定义对象，再利用范数控制或单调极限向更大的空间延拓。

无界算子引入了另一个必要条件：每一步运算都要有合适的定义域。闭图像和图像范数保证极限保留算子作用，伴随与亏空间描述扩张的可能性，闭形式则从能量表达式确定一个自伴算子。

紧性提供从近似中取得极限的方法。弱-\* 紧性控制测试值的极限；紧算子将有界弱收敛转化为范数收敛；紧预解式进一步带来离散特征值和特征函数展开。

## 3. 一个贯穿各章的边值问题 { #section-3 }

考虑

$$
-u''=f,\qquad u(0)=u(1)=0.
$$

弱形式为 $\int_0^1\overline{v'}u'=\langle v,f\rangle$。右端可以是能量空间上的有界泛函；正交投影给出 Galerkin 逼近；零边界条件进入形式域与算子域；逆算子的紧性使解能够按特征函数展开。相容性、稳定估计和收敛，需要在同一个明确的空间中讨论。
