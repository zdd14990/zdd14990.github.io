# 微分几何 { #index }

这份笔记前半部分讨论微分流形的基本语言：光滑结构、切向量与切丛、单位分解、向量场与单参数变换群、李群与李代数，以及微分形式、流形上的积分与 Stokes 定理和它们在物理中的应用。后半部分转向几何：流形上的联络与曲率，$\mathbb{R}^3$ 中曲线的 Frenet 标架，曲面的第一、第二基本形式与 Gauss 绝妙定理。
