#### 清浊辅音
* **浊辅音**：б, в, д, з, г, ж
* **清辅音**：п, ф, т, с, к, ш
* **清化规则**：浊辅音位于词末和清辅音前要清化。
* **浊化规则**：清辅音在浊辅音前要浊化（в 除外）。

#### 软硬辅音
* **硬辅音**：`а`, `о`, `у`, `э`, `ы`, `ъ` 前的辅音是硬辅音。
* **软辅音**：`я`, `ё`, `ю`, `е`, `и`, `ь` 前的辅音是软辅音。
* **永远发硬辅音**：`ц`, `ш`, `ж` 后面无论跟什么字母，它们永远发硬辅音。

#### 特殊拼写与发音规则
* **ц, ш, ж 与 ё, е 拼写时**：
  1. `ц`, `ш`, `ж` + `ё` 时，读作 `[о]`，如 *жё[о]лтый*, *пошё[о]л*（自带重音！）。
  2. `ц`, `ш`, `ж` + `е` 时：
     * 如果重音在 `е` 上，则 `е` 读作 `[э]`，如 *це[э]х*。
     * 如果重音不在 `е` 上，读音介于 `[ы]` 和 `[э]` 之间，如 *цена*, *жена*, *тоже*。
* **ц, ш, ж 与 и 拼写时**：`и` 读作 `[ы]`，如 *ци[ы]рк*, *ужи[ы]н*（书面上不与 `ы` 相拼写，即没有 шы, жы）。
* **г, к, х 的拼写限制**：不能和 `ы` 相拼（即没有 гы, кы, хы）。

### 动物名词 и 非动物名词

**名词**主要分为以下两类：

*   **动物名词**：表示**人**和**动物**的名词。比如：па́па 爸爸, ма́ма 妈妈, поэ́т 诗人, Анто́н 安东, Анна 安娜, кот 猫, у́тка 鸭子, соба́ка 狗.
*   **非动物名词**：表示**除人和动物以外**其它各种事物的名称。比如：окно́ 窗户, ко́мната 房间, сок 果汁。需要特别注意的是，**植物**是非动物名词，比如：тома́т 番茄, де́рево 树, цветы́ 花.

---

**疑问代词提问规则**：

*   ➢ **Кто?** （疑问代词 谁？）—— 提问**动物名词**
*   ➢ **Что?** （疑问代词 什么？）—— 提问**非动物名词**

### 名词的性

| 性 | 结尾 | 例词 |
| :--- | :--- | :--- |
| **阳性 он** | 硬辅音 + ч, щ | дом, го́род, Анто́н |
| | -й (-ий) | Кита́й, музе́й, санато́рий |
| | -ь | слова́рь, гость |
| **阴性 она** | -а | ко́мната, кни́га, де́вушка |
| | -я (-ия) | ку́хня, тётя, аудито́рия |
| | -ь | тетра́дь, ночь |
| **中性 оно** | -о | окно́, молоко́, сло́во |
| | -е (-ие) (-ё) | мо́ре, общежи́тие, бельё |
| | -мя | и́мя, вре́мя |

---

 **Внимание!**
 1. 表示人的名词或人名，按自然属性判断。（阳性：па́па, Воло́дя，阴性：ма́ма, Анна）
 2. 以 **-ь** 结尾的名词需要查字典确定是阳性还是阴性。

---

**阳性 (он)**
*   **слова́рь**（字典）
*   **гость**（客人）
*   **рубль**（卢布）

**阴性 (она)**
*   **тетра́дь**（笔记本 / 练习本）
*   **ночь**（夜晚）
*   **о́бувь**（鞋子）

**不变形的外来词（单复数同形，各格不变）：**
*   **фо́то**（照片，中性）
*   **кaфе**（咖啡馆，中性）
*   **ра́дио**（广播，中性）
*   **кино́**（电影院 / 电影，中性）

**无复数形式的名词：**
*   **пи́во**（啤酒，中性）
